# Source

This is not a model. It is a tiny, deterministic, non-model fixture that lets
Second Brain exercise its full verify -> download -> install flow against a
real signed catalog entry without downloading a real model.

- Repository: this repository, `github.com/JoshMcMillen/second-brain-models`
- Revision: `bc9f346cd6c906096b594a3c839d83facc150f7b` (a fixed identifier for
  this fixture's content, not a real upstream commit -- there is no external
  upstream; the bytes are generated by this repository's own tooling)
- Artifact source: `src/second_brain_models/canary.py`,
  `build_canary_artifact_bytes()` -- deterministically reconstructs the exact
  313-byte, zero-tensor GGUF container from source. It is never committed as
  a `.gguf` file, exactly like a real model's weights.
- Declared artifact size: `313` bytes
- Declared SHA-256: `6d7af954d2e55f0bb60e53d07d3383c3a0c65e09aef3c007a3e310ada201a190`
- License: `LICENSE` in this directory (CC0-1.0, self-authored)

Status: `test` channel, `approved`. Unlike a real candidate, the dedicated
`test` channel is not part of the candidate -> beta -> stable promotion
ladder and does not require the runtime family itself to have completed
separate owner-gated runtime approval (see `docs/promotion-policy.md`). Its
content is permanently fixed by this repository's own source and reviewed
once, as ordinary code review, rather than case by case.
